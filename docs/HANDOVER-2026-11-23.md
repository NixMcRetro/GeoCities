## 1. Purpose and guiding principles

Modernise the historical [despens/Geocities](https://github.com/despens/Geocities) preservation toolkit, originally intended for Ubuntu 12.04, for **Ubuntu 26.04 LTS** (primary) and **Ubuntu 24.04 LTS** (secondary). Recover/reconstruct the GeoCities web archive from historical collections with original filenames, URLs, timestamps, variants and provenance preserved wherever possible.

**Preservation first:** never destroy, silently rename, overwrite, deduplicate, or discard originals, including strangely named files, directories, symlinks, encodings and conflicting copies. Inventory and validate data before even considering destructive operations. Keep source data immutable and exports separate.

This project is about *reconstruction software*, not publishing the complete GeoCities dataset into GitHub. Archive content and software licensing are separate questions; the original toolkit uses AGPL-3.0-or-later. Retain attribution.

## 3. What the existing pilot actually does

The `develop-ubuntu-2604` branch includes:
- `geocities_rebuild/__main__.py`: read-only preflight and a capped SHA-256 directory inventory; detects case-fold filename collisions; records timestamps, symlink targets and base64-encoded original filesystem path bytes; refuses output inside source or to an existing manifest.
- `scripts/create_fixture.py`: creates a *new* tiny disposable tree with `Home` vs `home`, `INDEX.HTML` vs `index.html`, odd characters, newline in a filename, a sample GIF/MIDI, and a symlink loop. It refuses to overwrite an existing tree.
- `tests/test_foundation.py`: standard-library tests.
- `.github/workflows/compatibility.yml`: Ubuntu 24.04/26.04 compatibility matrix.
- `config.example.toml`, `.gitignore`, `docs/ROADMAP.md`, and original `LICENSE` / `agpl3.txt`.

**It is not a full reconstruction tool**: no archival 7z/tar extractor, no merging, database migrations, deduplication/provenance store, safe historical website serving or large-scale resumable run is implemented. The inventory deliberately defaults to a **10,000-entry cap** and holds results in memory. Do not deploy it against a multi-million-file collection.

## 5. Historical pipeline discoveries and known hazards

From previous inspection of upstream and the 2022 archive:
- `scripts/GeoURLs.pl` invokes removed/deprecated `gvfs-info` for MIME information. Consider `gio info -a standard::content-type` or appropriate GIO/MIME libraries, preserving historic behaviour through fixtures.
- `scripts/filter-indexes.pl` relies on deprecated Perl smartmatch (`~~`) and has fragile index-group handling.
- Upstream `geocities.archiveteam.torrent/013-indexes.sh` references a typo `filer-indexes.pl`; the 2022 archived variant already corrected it. Compare historical fixes before reimplementing.
- `scripts/remove-double-files.pl` has risky empty-set/end-of-stream behaviour and destructive duplicate handling.
- `scripts/merge_directories.pl` uses shell commands/backticks with path interpolation and destructive file moves; quoting, file names, metadata preservation and non-destructive conflict handling require redesign.
- `scripts/GeoIngest.pl` loads entire files to hash them and uses a legacy PostgreSQL ingestion approach. Replace with streaming hashes, explicit transaction handling and resumability; preserve old identifiers if compatibility needs them.
- The original Python proxy is Python 2/Twisted (`urlparse`) and must not be deployed as an unrestricted open proxy. Prefer a sandboxed, safe, static historical-host reconstruction server.
- Original archive downloader uses older HTTP links, shell snippets and unsafe filename interpolation. Prefer HTTPS manifests, explicit argument handling, checksum verification and resume support.
- Historical shell routines include `convmv --notest`, recursive `rm -rv` on specified paths, and hardcoded archive merges. The 2022 `006a-more-merging.sh` and `006b-merge-regions.sh` include destructive operations. **Never run these against original data as-is.**
- Source archive sets discussed include Archive Team, Chronomex, JCN, Latecomer, Santiago and other regional materials. Exact collection manifests, volume and verification status require a new audit. Do not assume complete copies are already downloaded.
